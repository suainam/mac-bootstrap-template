# 零售营运因果推断与多维合成控制评估规范 (ps-causal-evaluation)

本 Skill 规范零售连锁门店在营运政策、布局调优、品类扩缩、陈列变更等管理干预下的**可审查因果效应评估（Causal Evaluation）标准作业流**。
旨在消除“对比区域大盘截尾均值”、“拿小店对标大店”、“跨生命周期与店型错配”、“将大盘自然趋势冒充干预增量”等常见归因偏差，提供透明、客观、可复现的实证对比。

---

## 核心因果评估流程 (Steps)

```
[原始试点清单] ──► Step 1: 业务锁定日期锚定与四期滚动切片 (30D/60D/90D, C/H/L/LH 等长闭区间，无缓冲期)
                    │
                    ▼
[直营全量在营池] ──► Step 2: 候选池清洗与店型/生命周期 1:N 硬分层互锁 (事前历史O2O/DTP/老店，严禁跨层回退，门禁仅限事前)
                    │
                    ▼
[真实流水特征] ──► Step 3: 尺度不变性 MDM、SCM 动态分段优化、真实品类 JSD 测算与基线卡尺裁剪
                    │
                    ▼
[全量流水宽表] ──► Step 4: 双重差分 (DID) 净增量测算、两组独立评价与不确定性量化 (禁止DID相减断言优劣)
                    │
                    ▼
[交付与答辩] ──► Step 5: 金字塔 4-Sheet Excel、三页高管 HTML、技术 Q&A Markdown 与三方数值对账
```

### Step 1: 业务锁定日期锚定与四期等长滚动窗口切片

1. **业务确认/锁定日期策略（Fixed Date Policy，严禁主观外推）**：
   - **月度推进批次**：实施开始日严格取业务确认的完成月份月底加一天（$S_i = \text{MonthEnd}(T_i) + 1$）；
   - **按日跟踪批次**：实施开始日严格取业务确认的实际整改完成日加一天（$S_i = T_i + 1$）；
   - **特定专案/历史试点**：严格锁定为经业务核实确认的基准实施日；
   - **零缓冲期与零伪造**：严禁任意增加前后“缓冲期”，严禁编造促销记录或虚构业务上线日期。
2. **四期严格等长闭区间切片（支持 30D / 60D / 90D 视图）**：
   - **本期 (C)**：$[S_i, S_i + N - 1]$（闭区间，干预实施后在营期，天数严格等于 $N$）；
   - **上期 (H)**：$[S_i - N, S_i - 1]$（闭区间，干预实施前自身基准期）；
   - **同期 (L)**：$[S_i - 364, S_i - 364 + N - 1]$（闭区间，向前 364 天对齐星期分布，消除周末分布差异；但请注意 364 天不对齐农历节气与中秋国庆长假，不可将星期对齐等同于完全消除了季节性）；
   - **上期同期 (LH)**：$[S_i - 364 - N, S_i - 364 - 1]$（闭区间，同星期对齐的历史基准期）。
3. **有效测量完整性与非正分母保护**：
   - 严格区分计划天数（$N$）与有效测量天数（实际有营业与流水记录的天数），真实核验跨数据源聚合一致性；
   - 严格区分缺测（未上报/数据中断）与真实零销售（有营业但流水为 0）；
   - 严格保护分母：基期销售额 $\le 0$ 时，禁止强制计算同比（置为 NULL / 不可计算，严禁生成无穷大或强行填 0）。
4. **完成标准**：
   - 试点门店与候选对照店的四个周期在营天数守恒，有效测量天数明确披露，无残缺天数隐瞒。

### Step 2: 候选池清洗与 1:N 店型/生命周期硬分层互锁

1. **供体池污染隔离与事前门禁原则**：
   - 排除历史政策调优店、其他并发试验店；
   - 排除开业不满 365 天的新店（消除新店爬坡与开业大促噪音，锁死成熟老店池）；
   - **排除事前基期停业闭店、低流水异常店（基准期日均 $\le 100$ 元或客流 $\le 5$ 单）**：所有流水与订单过滤阈值必须**严格限定于事前基期观察值**，绝对禁止使用实施后的流水表现筛选候选池；
   - 若门店在实施后发生经业务证实的停业、迁址或不可抗力中断，应根据行政营运记录独立标记披露，严禁在事后静默重构供体池。
2. **三维店型硬分层互锁与禁止跨层回退**：
   - **DTP 门店**：严格在同营运区 DTP 候选子池中匹配；
   - **O2O 重点门店**：严格从实施前历史生效分区的官方维表（`dsl_dwd.dwd_ti_ec_key_stores_business_capacity`）提取，严禁使用“开通外卖平台（`is_o2o_layout`）”或干预后最新名单代替；
   - **常规成熟门店**：在成熟社区/商圈门店子池内匹配；
   - **严禁跨店型回退（No Cross-Stratum Fallback）**：当某店型候选供体不足时，必须客观披露供体不足与无法匹配原因，绝对禁止降级回退至常规成熟店混合匹配。
3. **尊重成熟老区域经营事实**：
   - 尊重根基深厚的成熟老区域真实经营定位与历史数据，严禁为迎合算法假设而编造营销活动、撤架断货或客群流失机制。
4. **完成标准**：
   - 候选池形成 1:N 充分竞争子池，跨店型错配率为 0；供体不足样本完整归入未匹配专表。

### Step 3: 四大集合数学边界、尺度不变性 MDM、SCM 动态分段优化与基线卡尺裁剪

因果匹配的核心防线在于**时序特征训练集与事前留出验证集的物理绝缘**，杜绝将未来信息或事后效果引入供体选择。

#### 1. 四大核心样本集合与严格数学边界 (The 4 Core Sets & Mathematical Boundaries)

```
[候选供体集 D_i] (成熟老店/同区同店型/基期正常/未污染)
      │
      ├─────────────────────────────────────────────┐
      ▼                                             ▼
[训练集 T_train: 90D~31D]                    [留出测试集 T_holdout: 30D~1D]
├─ seg1: [S_i-90, S_i-61] (及去年同期)       ├─ [S_i-30, S_i-1] (闭区间30天)
├─ seg2: [S_i-60, S_i-31] (及去年同期)       ├─ 严格单向绝缘防火墙 (Zero Leakage)
├─ 8 维时序特征向量 (销售/毛利/客流/同比)    │  (不参与标准化、MDM排序与门禁)
├─ 尺度不变性 MDM 粗排与 Top-K 初选          │
├─ SCM 自适应凸二次规划求解 (w_k >= 0)       │
├─ 训练集卡尺门禁仲裁 (Tier 1 / Tier 2 / 3)   │
│                                            │
▼                                            ▼
[最终入选对照集 C_i] ───────────────────────► 盲测诊断: Holdout RMSPE 测算
  ├─ Tier 1: 纯真实单店 (单店偏差<=10%)      │ (未见真实流水评估泛化能力，
  ├─ Tier 2: SCM 虚拟克隆 (合成偏差<=20%)    │  严禁反向调参或二次剔除)
  └─ Tier 3: 未获可比对照 (沉底未匹配专表)   │
      │                                      │
      ▼                                      ▼
进入 Step 4 四期等长 DDD 净增量闭环评估 ◄─────┴───────────────────────────────┘
```

- **集合 ① 候选供体集 (Control Donor Set, $\mathcal{D}_i$)**：
  - **业务定义**：与试点店 $i$ 处于**同营运区**、**同事前店型**（DTP / O2O 重点店 / 常规成熟店）的合规成熟在营候选池；
  - **资格门禁（事前硬门禁）**：开业成熟度 $\text{opert\_open\_date} \le S_i - 365\text{D}$（开业满 1 年，消除新店爬坡噪音）；排除历史政策调优店、并发试验店及试点店自身；事前基期正常经营（日均流水 $> 100$ 元且日均订单 $> 5$ 单）；事前 90 天流水记录完整（有效测量天数 = 计划天数）；
  - **店型隔离**：DTP 仅限同区 DTP、O2O 仅限历史生效分区的官方 O2O 重点店维表、常规成熟店仅限社区/商圈老店。供体不足时如实报告，**绝对禁止跨店型降级回退**。

- **集合 ② 训练集 (Training Set, $T_{\text{train}}$: seg1 & seg2)**：
  - **业务定义**：实施日前 90D~31D（共 60 天），分为两段严格等长 30 天闭区间：
    - **seg1**：$[S_i - 90, S_i - 61]$（及去年星期对齐同期 $[S_i - 90 - 364, S_i - 61 - 364]$）；
    - **seg2**：$[S_i - 60, S_i - 31]$（及去年星期对齐同期 $[S_i - 60 - 364, S_i - 31 - 364]$）。
  - **数学边界与用途**：
    - 提取 8 维分段时序特征向量：
      $$X = [\bar{S}_{\text{seg1}}, \bar{S}_{\text{seg2}}, \bar{\Pi}_{\text{seg1}}, \bar{\Pi}_{\text{seg2}}, \bar{O}_{\text{seg1}}, \bar{O}_{\text{seg2}}, g_{\text{YoY, seg1}}, g_{\text{YoY, seg2}}]$$
      其中 $\bar{S}, \bar{\Pi}, \bar{O}$ 分别为日均销售额、日均毛利额、日均订单量，$g_{\text{YoY}}$ 为相对去年同期的同比增长率；
    - 在标准化特征空间中利用供体离散度与正则化逆协方差计算马氏距离（MDM），进行供体初排；
    - 选取 Top-K（通常 $K=2\sim 3$）供体矩阵 $X_{\text{donors}}$ 与目标向量 $x_{\text{pilot}}$，执行 SCM 凸二次规划权重求解；
    - 裁决训练期单店与合成克隆的销售偏差、毛利偏差、订单偏差、走势偏差及综合拟合度（$\text{Fit RMSPE}$）。

- **集合 ③ 留出测试集 (Holdout Test Set, $T_{\text{holdout}}$)**：
  - **业务定义**：实施日前 30D~1D（共 30 天，闭区间 $[S_i - 30, S_i - 1]$），作为模型未见的事前盲测验证集；
  - **核心铁律（防火墙隔离与零泄漏）**：
    - **严格单向绝缘（Strict Out-of-Sample Firewall）**：在特征计算、空间标准化、MDM 排序、SCM 凸权重求解及 Tier 1/2/3 门禁裁决中，**100% 绝对物理绝缘，严禁使用留出集任何数据**；
    - **事后盲测诊断（Post-hoc Diagnostic Only）**：在对位对照（单店或 SCM 权重向量）完全确定后，在未见区间计算 Holdout RMSPE / 留出销售偏差：
      $$\text{Holdout RMSPE} = \frac{|\sum_{k} w_k S_{k, \text{holdout}} - S_{i, \text{holdout}}|}{\max(S_{i, \text{holdout}}, 1)}$$
    - 仅作为反事实模型时序泛化能力的自验证据披露于过程质量区，**严禁利用留出误差反向调整 SCM 权重或反向筛选/剔除门店**！

- **集合 ④ 最终入选对照集 (Final Matched Control Group, $\mathcal{C}_i$)**：
  - **业务定义**：经过训练集门禁和卡尺仲裁后，最终与试点店结对进入 Step 4 差分测算的对照实体；
  - **分层仲裁漏斗（Tiering Funnel）**：
    - **Tier 1 (纯真实单店)**：MDM 排名第 1 的真实候选单店在训练集上满足严格门禁（$|\Delta S_{\text{train}}| \le 10\%$、$|\Delta O_{\text{train}}| \le 10\%$、$|\Delta \text{YoY}_{\text{train}}| \le 15\text{pp}$），优先采用真实单店（权重 $w=1.0$），保持最高可解释性；
    - **Tier 2 (SCM 虚拟克隆)**：单店未达标，但 Top-K 供体经凸优化合成出的虚拟克隆在训练集上满足合成门禁（$\text{Fit RMSPE} \le 1.0$、$|\Delta S_{\text{scm}}| \le 20\%$、$|\Delta \text{YoY}_{\text{scm}}| \le 20\text{pp}$），入选为虚拟克隆对位对照组（赋予凸组合权重向量 $w$）；
    - **Tier 3 (未获可比对照排除区)**：单店与 SCM 均无法达标，或同层候选池为空，沉底归入未匹配专表（记录客观原因编码如 `NO_SAME_STRATUM_DONOR`、`BASELINE_FIT_OUTSIDE_CALIPER`），**严禁跨层降级回退**。

#### 2. 尺度不变性标准化空间马氏距离 (MDM)
在同店型候选池特征矩阵进行标准化（减均值除标准差 $z = \frac{x - \mu}{\sigma}$）后，利用正则化协方差逆矩阵计算马氏距离：
$$D_M(z_i, z_j) = \sqrt{(z_i - z_j)^T \mathbf{\Sigma}_{\text{reg}}^{-1} (z_i - z_j)}$$
其中 $\mathbf{\Sigma}_{\text{reg}} = (1 - \alpha)\mathbf{\Sigma} + \alpha \mathbf{I}$ 为加入对角岭的正则化协方差矩阵（默认 $\alpha = 0.01$）。
- **尺度不变性检验**：指标金额单位无论以“元”还是“万元”计入，标准化后的马氏距离与供体排序严格一致。

#### 3. SCM 自适应凸组合优化求解与目标透明化
对目标试点店 $i$ 及 Top-K 候选供体（$K=2\sim 3$）：
$$\min_w \| X_{\text{donors}} w - x_{\text{pilot}} \|^2 \quad \text{s.t.} \quad \sum_{k=1}^K w_k = 1, \quad w_k \ge 0$$
- **特征全面覆盖**：特征矩阵 $X$ 必须覆盖训练集 seg1 与 seg2 的销售额、毛利额、订单量及同比走势；
- **毛利与目标透明化**：明确披露毛利是否进入二次规划优化目标。若毛利纳入目标优化，如实列出权重；若毛利仅按销售权重线性合成，必须客观说明，严禁宣称毛利已被最优合成。

#### 4. 真实品类结构相似度 (Jensen-Shannon Distance，零虚假填充)
- 提取干预实施前各大类真实流水占比 $P, Q$，计算：
  $$JSD(P, Q) = \sqrt{\frac{1}{2} D_{KL}(P \parallel M) + \frac{1}{2} D_{KL}(Q \parallel M)}, \quad M = \frac{1}{2}(P + Q)$$
- **同构门禁要求**：$JSD \le 0.20$；若某批次事前大类数据缺失，必须真实标记为缺失（NULL / 未测），**严禁使用任何经验常数（如 0.0888）硬编码填充**。

#### 5. 规则驱动的基线硬卡尺裁剪与客观隔离 (杜绝事后选择偏差)
配对候选对必须经由训练集基线硬卡尺检验，触发任一门禁的门店沉底归入 Tier 3 排除区：
- **卡尺 ① 训练期销售体量偏差**：$|S_{\text{ctrl, train}} - S_{\text{pilot, train}}| / S_{\text{pilot, train}} > 20.0\%$（超出共同支撑集）；
- **卡尺 ② 训练期走势偏差**：$|\text{YoY}_{\text{ctrl, train}} - \text{YoY}_{\text{pilot, train}}| > 20.0\text{pp}$（偏离基期平行走势）；
- **卡尺 ③ 供体历史基期不连贯**：对照供体去年同期曾停业跌幅 $> 70.0\%$ 或暴涨 $> 150\%$（基期数据断裂不可比）；
- **杜绝事后选择偏差（No Conditioning on Post-Treatment Outcomes）**：
  - 卡尺裁剪完全基于实施前训练集的基线特征；
  - **严禁根据实施后的销售涨跌或 DID 结果反向剔除门店或调整参数**；
  - 若门店在实施后发生经业务证实的停业、迁址或不可抗力中断，应根据行政营运事实如实归档为行政受扰样本并独立披露，不可通过事后业绩跌幅门禁隐性筛选。

#### 6. 完成标准
- 试点门店明确划分入 Tier 1（单店 $\le 10\%$）、Tier 2（SCM $\le 20\%$）或 Tier 3（未获可比对照排除专表）；
- 留出测试集盲测 Holdout RMSPE 独立计算并如实填报，无数据逆向污染。
### Step 4: 三重差分 (DDD / YoY-DID) 净增量测算、两组独立评价与不确定性量化

1. **三重差分 (DDD) 因果架构与算式闭环**：
   - 零售门店天然受“月度季节性与长假周期”及“商圈固有底色惯性”双重影响，传统单重或未对齐季节的双重差分极易产生归因失真；
   - 必须严格执行**三重差分（DDD，差分的差分）**闭环：
     $$\text{DDD} = \underbrace{(\text{YoY}_{\text{pilot, post}} - \text{YoY}_{\text{pilot, pre}})}_{\Delta_{\text{试点提速增量}}} - \underbrace{(\text{YoY}_{\text{ctrl, post}} - \text{YoY}_{\text{ctrl, pre}})}_{\Delta_{\text{对照组提速增量}}}$$
   - **闭环完整性守恒**：明细交付必须同时报告“基期同比”、“实施后同比”与“提速增量”，绝对禁止只呈现实施后同比而产生“$\text{DID} \ne \text{试点后} - \text{对照后}$”的业务困惑。
2. **两组独立评价原则（Dual Cohort Separation，禁止跨批次 DID 相减）**：
   - 算法模型试点组（如 2026 年 72 店）与历史业务手工组（如 2025 年 244 店）为不同年份、不同区域、不同宏观背景的非并发观察样本；
   - **严禁将两组的 DID 净增量直接相减并断言“算法优于或劣于人工”**；两组必须完全物理隔离，独立核算 30D / 60D / 90D 的实证成效。
3. **分营运区/批次审慎定性红线（样本量阶梯原则）**：
   - 下钻区域样本量 $\le 2$ 家时，必须严格定性为 **`单店个案 · 供参考`**，**绝对禁止标注“大样本”字眼**；
   - 仅当区域样本量 $\ge 15$ 家时，方可标记为“大样本区域”。
4. **客单价与不确定性量化**：
   - **客单价（ATV）计算**：严格按 $\text{ATV} = \frac{\text{Sales}}{\text{Orders}}$ 真实流水比值直算；
   - 报告组合汇总效果、平均店级效果（Mean Store-Level DID）及 95% 置信区间。

### Step 5: 金字塔 4-Sheet Excel 与三层高管 HTML 标准交付

1. **4-Sheet 独立交付 Excel 工作簿（72店与244店必须分拆两份独立工作簿）**：
   - **Sheet 1 评估结论总览**：
     - 表头必须显式锁定业务指标名称（如 `试点前销售同比(%)`、`试点店销售增量(pp)`、`DID销售净增量(pp)`），杜绝与毛利、客流混淆；
     - 包含核心合格配对大盘（30D/60D/90D）、分区域/分批次下钻、不可比排除门店专表三模块。
   - **Sheet 2 试验组与对照组详细门店及指标**：
     - **业务实证结果区与算法拟合过程区彻底解耦**；
     - **结果区**：展示试点与对照各自的完整 DDD 链条（基期同比 $\rightarrow$ 后同比 $\rightarrow$ 增量 $\rightarrow$ DID净增量）；
    - **过程质量区**：仅展示参与硬约束与诊断的 **最终拟合销售偏差、毛利偏差、走势偏差、品类JSD、留出测试集盲测 Holdout RMSPE**，以及 1:1 单店锚点偏差（解释启用 SCM 虚拟合成的必要性）；**未纳入硬门禁约束的冗余指标（如无约束的客流偏差）坚决不展示**。
   - **Sheet 3 候选池分层与虚拟合成溯源**：供体池画像与 SCM 各供体权重精确到 $0.1\%$。
   - **Sheet 4 口径说明与计算字典**：DDD 闭环公式、四重卡尺门禁与术语定义。
2. **高管与业务汇报 HTML 交互大屏（CONSORT-grade 架构）**：
   - **职责定位**：定位为大盘概览与区域下钻决策，**彻底移除冗长逐店明细表（以清晰 Callout 导流至对应 Excel）**；
   - **CONSORT 矢量流转图规范**：
     - 严格使用行业标准专业术语：**`DTP 门店`**、**`O2O 重点店`**、**`常规成熟店`**，绝对禁止使用“外卖”、“专科”等非标准口语化词汇；
     - 72 店与 244 店必须绘制各自专属的 SVG 漏斗图，严禁混用样本量与分层数据；
     - 采用 Blueprint / Modern Analytical 高对比度排版，字号严格分级，全面适配暗色与浅色模式。

## 攻防防线与汇报考量指南 (Adversarial Defenses)

| 潜在挑刺点 / 质疑 | 模型方 / 业务方抗辩预判 | 规范因果推断评估视角 (证据与边界) |
|:---|:---|:---|
| **施工磨合期干扰** | “调优后初期在搬货架、动线磨合，拉低了短期业绩” | **多周期联合观察**：综合 30D、60D、90D 多个窗口的动态走势进行观察。若中长期净增量依然未见超额表现，初期施工扰动假设的解释力度将显著减弱；同时需结合实际营业记录核实是否有实际停业天数。 |
| **对照组大促干扰** | “对照店在同期上涨，是不是对照店刚好做了大促？” | **供体结构核验与基期走势诊断**：①需输出 SCM 真实供体权重分布与集中度；若单一供体权重过高或供体共享外部冲击，偶发促销无法被自动稀释；在缺乏同期营销活动明细时，促销干扰假说属于未经核实的事项；②报告实际的事前走势检验统计量、分段相对走势差异及留出拟合诊断，客观呈现干预前轨迹匹配情况，不作任何预设检验结论。 |
| **大盘自然回暖假象** | “某报告显示试点店环比提升，说明调优有效” | **双重差分剥离共同趋势**：若行业大盘或商圈在干预期间出现季节性反弹，试点店与同类型可比对照店均会受到宏观趋势影响。双重差分在满足平行趋势假定下，旨在扣除宏观共同变动部分，提炼出策略的相对净增量。 |
| **两组批次优劣对比** | “模型批次 DID 与历史业务批次 DID 谁高谁就更强” | **非并发观察样本隔离**：不同批次处于不同年份、不同宏观经济周期与不同门店基线，缺乏同期随机分组基础；两组必须分别独立评价，严禁将 DID 差值断言为因果优劣。 |
| **供体不足降级匹配** | “DTP/O2O 店候选样本少，降级到普通店匹配是否可行？” | **店型隔离原则**：商业模式与客群完全异构（如 DTP 集中于高单价处方药、O2O 受线上平台即时履约影响），跨店型匹配会引入严重选择性偏误；供体不足时必须如实报告无法匹配，严禁跨层回退。 |
