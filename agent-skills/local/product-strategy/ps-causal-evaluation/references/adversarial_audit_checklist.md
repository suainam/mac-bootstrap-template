# 因果推断对抗性审查审计防线 (Adversarial Audit Checklist)

任何基于本 Skill 产出的 DID 评估报告、工作簿及交付看板，必须通过以下 8 维对抗性审查：

### Gate 1: 数据源头与业务锁定日期门禁验证 (Fixed Date Policy)
- [ ] **业务锁定日期对齐**：
  - 月度推进批次干预开始日是否严格等于业务确认的完成月份月底加一天（$S_i = \text{MonthEnd}(T_i) + 1$）；
  - 按日跟踪批次干预开始日是否严格等于业务确认的实际整改完成日加一天（$S_i = T_i + 1$）；
  - 特定专案或历史试点干预开始日是否严格锁定为经业务核实确认的基准实施日；
  - 严禁擅自加入前后缓冲期，严禁编造促销记录或虚构业务上线日期。
- [ ] **权威维表事前真身**：
  - O2O 重点门店是否取自实施前历史生效分区的官方真身表 `dwd_ti_ec_key_stores_business_capacity`（严禁使用 `is_o2o_layout` 外卖开通字段或干预后名单代替）；
  - 维表缺失时必须 **Fail-Closed（报错终止）**，严禁使用随机模拟或均值填充。

### Gate 2: 流水全量覆盖、真实零销售 vs 缺测与分母保护
- [ ] **有效测量天数 vs 计划天数**：
  - 报表必须显式披露每个分析窗口（30D/60D/90D）的计划天数与实际有效测量天数，杜绝将缺测误当做全期在营；
  - 明确周期定义为闭区间 $[S_i, S_i + N - 1]$；
  - 客观披露 364 天仅对齐星期，并不对齐农历节气或宏观季节波动；
  - 跨数据源聚合时店日主键 `store_code + stat_date` 必须严格去重，正确区分缺测（未上报）与真实零销售（有营业但流水为 0）。
- [ ] **非正分母保护**：
  - 当基期销售额 $\le 0$ 时，禁止强制计算同比增长率（必须置为 NULL，严禁出现无穷大或硬填 0）。

### Gate 3: 事前历史分层与禁止跨层回退 (No Fallback)
- [ ] **严格店型隔离**：
  - DTP 门店必须在同区 DTP 子池匹配，O2O 重点门店必须在同区 O2O 重点池匹配，常规成熟店在常规成熟池匹配；
  - 当同店型候选供体不足时，必须客观报告供体不足与无法匹配原因，**绝对禁止跨店型回退至常规成熟店混配**。
- [ ] **尊重成熟老区事实**：
  - 尊重深厚根基的发源地/成熟老区域真实经营定位与历史数据，严禁编造营销活动、撤架断货或客群流失机制。

### Gate 4: 四大集合数学边界、训练/留出绝缘与 SCM 凸优化审计
- [ ] **四大集合边界与严格时间窗口**：
  - 候选供体集：开业满 365 天（$\text{opert\_open\_date} \le S_i - 365\text{D}$），无历史政策调优/并发试验污染，事前基期日均流水 $> 100$ 元且客流 $> 5$ 单；
  - 训练集（60天）：seg1 $[S_i - 90, S_i - 61]$ 与 seg2 $[S_i - 60, S_i - 31]$，提取销售、毛利、订单、同比共 8 维分段时序特征；
  - 留出测试集（30天）：$[S_i - 30, S_i - 1]$，作为事前模型未见的盲测验证集。
- [ ] **留出验证防火墙与零泄漏 (Zero Leakage)**：
  - 留出集 30 天数据**100% 绝对不参与特征标准化、MDM 距离计算、SCM 凸组合权重求解与门禁卡尺裁决**；
  - 留出测试集仅在对照组锁定后用于计算 Holdout RMSPE 泛化诊断值，**绝对禁止利用留出集误差反向调整权重或二次筛选门店**。
- [ ] **标准化空间 MDM 尺度不变性**：
  - 马氏距离必须在标准化特征空间中利用供体离散度与正则化逆协方差计算；
  - 必须通过尺度不变性检验：金额单位由元转为万元、客流单位变化等线性变换，不得改变配对排序与距离。
- [ ] **SCM 自适应凸组合优化目标透明化**：
  - 优化目标：$\min_w \| X_{\text{donors}} w - x_{\text{pilot}} \|^2 \quad \text{s.t.} \quad \sum w_k = 1, w_k \ge 0$；
  - 明确披露优化目标涵盖的 8 维分段特征；明确毛利是否进入目标（若未优化仅按销售权重合成，必须如实披露，不得虚假宣称毛利已被最优合成）。

### Gate 5: 真实品类 JSD、Tier 1/2/3 门禁与零事后选择偏差
- [ ] **真实品类 JSD（零常数填充）**：
  - 品类 JS 散度必须基于干预实施前各大类真实流水占比计算；
  - 若某批次事前大类数据缺失，必须真实标记为缺失（NULL / 未测），**严禁使用任何经验常数（如 0.0888）硬编码填充**。
- [ ] **分层门禁仲裁漏斗（Tier 1 / Tier 2 / Tier 3）**：
  - Tier 1（纯真实单店）：训练集单店销售偏差 $\le 10\%$、订单偏差 $\le 10\%$、走势偏差 $\le 15\text{pp}$；
  - Tier 2（SCM 虚拟克隆）：训练集综合拟合度 $\le 1.0$、SCM 销售偏差 $\le 20\%$、走势偏差 $\le 20\text{pp}$；
  - Tier 3（未获可比对照）：单店与 SCM 均未达标或同层候选池为空，沉底归入未匹配专表（记录原因如 `NO_SAME_STRATUM_DONOR`、`BASELINE_FIT_OUTSIDE_CALIPER`），**严禁跨层降级回退**。
- [ ] **基线硬卡尺与杜绝事后选择偏差**：
  - 卡尺裁剪完全基于实施前训练集基线特征：事前销售偏差 $> 20.0\%$、事前走势差异 $> 20.0\text{pp}$、对照供体基期断崖跌幅 $> 70.0\%$ 或暴涨 $> 150\%$；
  - 严格杜绝根据实施后涨跌（如干预后跌幅）反向筛选样本或调优卡尺参数；排除门店必须在专表完整披露客观原因。

### Gate 6: 双组独立评价、客单价与不确定性量化
- [ ] **完整三重差分 (DDD) 闭环**：
  - 严格执行 $\text{DDD} = \Delta_{\text{试点提速增量}} - \Delta_{\text{对照组提速增量}}$，明细表必须同时报告基期同比、后同比、增量与 DID 净增量，守恒闭环。
- [ ] **两组独立评价（禁止 DID 直接相减）**：
  - 算法模型试点批次与历史业务调整批次为不同时期的非并发、非随机分组观察样本；
  - **严禁将两组的 DID 估计值直接相减并解释为“模型相对人工经验的因果优势/劣势”**；两组必须分别独立呈现 30D / 60D / 90D 的评估结果与差异归因。
- [ ] **客单价公式合规**：
  - 客单价必须严格按 $\text{ATV} = \frac{\text{Sales}}{\text{Orders}}$ 计算，订单为 0 时置为未定义/NULL，严禁颠倒为 orders/sales。
- [ ] **双轨报告与供体复用不确定性**：
  - 同时报告组合汇总效果（Portfolio Aggregate DID）与单店平均效果（Average Store-Level DID）；
  - 必须提供标准误与置信区间，并显式考虑同一供体店被多家试点店复用时的相关性（Clustered/Reused Donor Standard Errors）；
  - 30D/60D/90D 比较中保持固定对照基准池，并客观披露样本衰减情况。

### Gate 7: 三模态交付物 100% 逐项守恒对账与两区解耦
- [ ] **金字塔 4-Sheet Excel 结构合规**：
  - Sheet 1 评估结论总览（大盘汇总、区域下钻、不可比排除专表）；
  - Sheet 2 试验组与对照组详细门店及指标：**业务实证结果区（完整 DDD 链条）与算法拟合过程区（拟合偏差、JSD、Holdout RMSPE、单店锚点）彻底解耦**，未约束指标坚决不展示；
  - Sheet 3 候选池分层与虚拟合成溯源（供体画像与 SCM 权重）；
  - Sheet 4 口径说明与计算公式（DDD 闭环、卡尺门禁与术语定义）。
- [ ] **三页高管 HTML 看板**（Page 1 结论建议与实证事实、Page 2 因果推断核心逻辑与归因、Page 3 极简流转流程及典型案例，彻底移除冗长表格）；
- [ ] **技术 Q&A Markdown 答疑**；
- [ ] 三类交付物中的样本量、排除数、关键指标数值必须 **100% 逐项完全守恒**；
- [ ] 增量与 DID 净增量全量统一标注为 `(pp)`，禁止与基准比率 `%` 混淆；杜绝画蛇添足的重复对账列。

### Gate 8: 结论表述审慎与避免虚假确定性承诺
- [ ] **审查事前诊断，不预设结论**：
  - 审查事前诊断指标（包括平行趋势检验统计量、分段相对走势差异及留出验证拟合度），核查干预前两组轨迹匹配质量，严禁预设检验结果或宣称“铁证证明完全同频”；
  - 长期窗口（60D/90D）分析客观表述为动态追踪，不可草率断言“彻底排除了所有外部施工干扰”；
  - 双重差分客观表述为“在满足平行趋势假定下剥离宏观共同时间趋势”，不可过度推论为消除了所有混杂。
