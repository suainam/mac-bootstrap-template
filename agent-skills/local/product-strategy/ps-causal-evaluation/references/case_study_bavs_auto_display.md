# 实战案例复盘：零售营运布局优化因果推断方法论演进

## 一、 背景与业务分歧

在零售连锁门店的陈列与布局调优中，评估团队与业务部门常面临因果归因争议：
- 传统商分报告常采用“试点店增长率与营运区截尾平均值对比”，得出“试点店缩小了与大盘的差距，因而模型/策略有效”的结论；
- 公司管理层与一线业务部门提出深刻质疑：营运区大盘包含大量边缘衰退小店，大盘均值是否被低效小店严重拉低？试点店的回暖是否仅仅是大盘夏秋交替的自然季节性反弹？模型相对人工经验是否有真实的因果超额收益？
- 为回答上述关切，因果推断评估规范确立了严格的反事实对照与双重差分框架。

---

## 二、 常见对比口径的方法学风险与审查考量

审查传统对比分析逻辑，识别出 5 处需高度警惕的方法学风险：

### 1. 方法风险 1：算术简单平均截尾 vs 金额加权（小店拖累效应风险）
* **方法机制**：若在计算大盘基准时先对每家对照店计算个体增长率并取简单算术平均，大盘中大量业绩低迷、日销微弱的边缘小店将获得与核心主力大店相同的权重。
* **审查考量**：若样本内包含较多衰退小店，简单算术平均在理论上会赋予低销小店过高的方差权重，可能拉低大盘平均线。这一拖累风险的大小取决于样本内小店的实际占比与离群程度，属于方案设计需防范的结构性风险，而非在缺乏实测核验前可直接假定的事实结论。

### 2. 方法风险 2：多重截尾过滤的样本选择偏差风险 (Double Trimming)
* **方法机制**：若在 SQL 阶段与后续脚本阶段对样本增长率或两组差距进行多次分位数截尾过滤。
* **审查考量**：多轮截尾可能剔除两端较多的极端样本（包括表现不佳、差距扩大的案例），存在引入幸存者偏差的统计风险。

### 3. 方法风险 3：统计假设检验形式与置信水平设定风险
* **方法机制**：若在具有选择性筛选特征的样本上采用单尾假设检验并配合较宽松的显著性水平。
* **审查考量**：单边假设检验对单向变动更为敏感，在样本非随机分布时可能增加假阳性（Type I Error）风险，放大边缘效应。

### 4. 方法风险 4：店型与生命周期异质性混淆风险
* **方法机制**：若直接使用营运区全量门店作为对照池，未区分 DTP 门店、O2O 重点店和常规成熟店。
* **审查考量**：不同店型的政策敏感度、客群画像及履约模式迥异（如 DTP 受处方药政策影响、O2O 受即时零售平台补贴与运力影响）；混同匹配必然引入不可观测的结构性混淆。

### 5. 方法风险 5：未受控的宏观共同趋势与季节性归因风险
* **方法机制**：若在行业季节性波动或节庆交替期，仅根据试点店环比回升直接归因为干预效果。
* **审查考量**：若同商圈同体量的对照门店同步出现自然走势变动，缺乏反事实对照会产生归因混淆。双重差分框架的核心价值在于引入可比对照以控制宏观共同趋势，但若缺乏真实同期营销记录或细分品类证据，不可单凭大盘季节性进行主观推断。

## 三、 因果评估规范的重构与纠偏准则

针对上述方法学考量，规范确立了以下重测标准：

### 1. 业务确认/锁定日期策略 (Fixed Date Policy)
- 历史业务调整批次干预开始日严格取业务确认的完成月份月底加一天；
- 算法模型试点批次干预开始日严格取业务确认的实际整改完成日加一天；
- 历史特定试点（如茂名）干预开始日严格锁定为业务确认日（2025-08-01）；
- 严禁擅自加入前后缓冲期，严禁编造促销记录或虚构上线日期。

### 2. 严格 1:N 店型分层与禁止跨层回退
- 严格基于实施前生效的权威历史 O2O 重点店名单与 DTP 资质进行硬分层；
- 当某店型候选供体不足时，必须如实报告供体不足，绝对禁止跨店型降级回退至普通店混配；
- 尊重茂名等成熟老区域真实经营事实，不编造营销活动、撤架断货或客流流失机制。

### 3. 四大集合数学边界、尺度不变性 MDM 与动态 SCM
- **候选供体集**：从全量直营池中严格按营运区、事前历史店型（DTP / O2O 重点店 / 常规成熟店）分层，开业满 365 天，基期正常营业；
- **训练集 (seg1 & seg2)**：实施日前 90D~31D（共 60 天），细分为 seg1 $[-90, -61]$ 与 seg2 $[-60, -31]$（及去年星期对齐同期），提取销售额、毛利额、订单量、同比增速等 8 维时序特征，执行标准化空间 MDM 距离初排与 SCM 自适应凸二次规划求解；
- **留出测试集 (Holdout Validation)**：实施日前 30D~1D（共 30 天，闭区间），建立严格单向防火墙，绝不参与特征标准化、优化求解与门禁裁决；仅在对照组锁定后测算 Holdout RMSPE 盲测诊断指标，检验时间反事实泛化能力；
- **对照集三层分流 (Tier 1 / Tier 2 / Tier 3)**：
  - Tier 1 (纯真实单店，单店偏差 $\le 10\%$)：模型 72 店入选 46 家，历史 244 店入选 72 家；
  - Tier 2 (SCM 虚拟克隆，合成偏差 $\le 20\%$)：模型 72 店入选 16 家，历史 244 店入选 89 家；
  - Tier 3 (未获可比对照排除区)：模型 72 店 10 家，历史 244 店 83 家，客观隔离沉底至未匹配专表，坚决杜绝跨层回退混配；
- **真实品类 JSD**：从干预前真实大类流水占比测算（$JSD \le 0.20$），无数据如实标为缺失（NaN），严禁常数伪造。
### 4. 两组独立评价，严禁直接相减 (Dual Cohort Separation)
- 算法模型试点批次与历史业务批次为不同时期的非并发、非随机分组观察样本；
- **严禁将两组的 DID 估计值直接相减并解释为“模型相对人工经验的因果优势/劣势”**；
- 两组必须分别独立呈现 30D / 60D / 90D 的评估结果与差异归因；
- 未经因果识别的粗糙物理指标（如货架米数变化）缺乏平行趋势与混杂控制，不可轻率推演为因果机制。

### 5. 三模态交付物 100% 逐项守恒对账与两区解耦
- 4-Sheet Excel（Sheet 2 业务实证结果区与算法拟合过程区彻底解耦，过程区展示 Holdout RMSPE 与单店锚点）、3-Page HTML（聚焦大盘决策与 CONSORT 漏斗流转，移除逐店长表）、技术 Q&A Markdown 三者之间的样本量、排除数、DID 指标数值必须 100% 逐项完全对齐，杜绝口径冲突与版本漂移。
