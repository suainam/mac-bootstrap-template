# 零售营运因果推断方法论标准操作规程 (SOP)

## 一、 业务锁定日期策略与四期滚动切片架构

因果评估必须建立在真实、确定、客观的时间锚点之上，严禁主观外推或随意平移。

### 1. 业务确认/锁定日期策略 (Fixed Date Policy)
- **月度推进批次**：实施开始日严格取业务确认的完成月份月底加一天（$S_i = \text{MonthEnd}(T_i) + 1$）；
- **按日跟踪批次**：实施开始日严格取业务确认的实际整改完成日加一天（$S_i = T_i + 1$）；
- **特定专案/历史试点**：严格锁定为经业务核实确认的基准实施日；
- **零缓冲期与零伪造**：严禁任意增加前后“缓冲期”，严禁编造促销记录或虚构业务上线日期。

### 2. 四期严格等长闭区间切片 (30D / 60D / 90D)
对每一个分析窗口 $N \in \{30, 60, 90\}$：
- **本期 (C, Current Post-intervention)**：$[S_i, S_i + N - 1]$（闭区间）；
- **上期 (H, Historical Pre-intervention)**：$[S_i - N, S_i - 1]$（闭区间）；
- **同期 (L, Last Year Post-intervention)**：$[S_i - 364, S_i - 364 + N - 1]$（闭区间，向前 364 天对齐星期分布，消除周末效应；但请注意 364 天不对齐农历节气与中秋国庆长假，不可将星期对齐等同于完全消除了季节性）；
- **上期同期 (LH, Last Year Pre-intervention)**：$[S_i - 364 - N, S_i - 364 - 1]$（闭区间）。

### 3. 有效测量天数与非正分母保护
- 严格区分计划天数（$N$）与有效测量天数（真实有营业与流水上报的天数）；
- 跨数据源聚合时核验店日主键唯一性，正确区分缺测（未上报/数据中断）与真实零销售（有营业但无销售）；
- 严格保护同比分母：当基期销售额 $\le 0$ 时，禁止强制计算同比，置为 NULL / 不可计算，严禁生成无穷大或强行填 0。

## 二、 CONSORT 1:N 硬分层与候选池清洗架构

因果推断的核心前提：**异质性样本绝对不可直接加权平均**。必须先做硬性离散分层，再做连续特征匹配。

### 1. 供体池清洗与事前门禁原则
- 排除历史政策调优店、其他并发试验店；
- 候选池必须通过 `opert_open_date <= anchor_date - 365 days` 强制剔除开业不满 1 年的成长期门店，消除新店爬坡与开业大促噪音；
- **排除事前基期停业闭店、低流水异常店（基准期日均 $\le 100$ 元或客流 $\le 5$ 单）**：所有流水与订单过滤阈值必须**严格限定于事前基期观察值**，绝对禁止使用实施后的流水表现筛选候选池；
- 若门店在实施后发生经业务证实的停业、迁址或不可抗力中断，应根据行政营运记录独立标记披露，严禁在事后静默重构供体池。

### 2. 店型硬分层互锁与禁止跨层回退
- **DTP 门店** $\to$ 仅在同营运区 DTP 候选子池中匹配；
- **O2O 重点门店** $\to$ 严格取自实施前历史生效分区的官方维表（`dsl_dwd.dwd_ti_ec_key_stores_business_capacity`），严禁使用“开通外卖平台（`is_o2o_layout`）”或干预后最新名单代替；
- **常规成熟门店** $\to$ 在社区、商圈成熟直营店子池中匹配；
- **禁止跨层回退（No Cross-Stratum Fallback）**：当同店型候选供体不足时，必须客观披露供体不足与无法匹配原因，绝对禁止降级回退至常规成熟店混配。

### 3. 尊重成熟老区域经营事实
- 尊重深厚根基的发源地/成熟老区域真实经营定位与历史数据，严禁为迎合算法假设而编造营销活动、撤架断货或客群流失机制。

## 三、 四大集合数学边界、尺度不变性 MDM 与 SCM 动态分段优化

因果匹配的核心防线在于**时序特征训练集与事前留出验证集的物理绝缘**，杜绝将未来信息或事后效果引入供体选择。

### 1. 四大核心样本集合与严格数学边界 (The 4 Core Sets)

```
[候选供体集 D_i] (成熟老店/同区同店型/基期正常/未污染)
      │
      ├─────────────────────────────────────────────┐
      ▼                                             ▼
[训练集 T_train: 90D~31D]                    [留出测试集 T_holdout: 30D~1D]
├─ seg1: [S_i-90, S_i-61] (及去年同期)       ├─ [S_i-30, S_i-1] (闭区间30天)
├─ seg2: [S_i-60, S_i-31] (及去年同期)       ├─ 严格单向绝缘防火墙 (Zero Leakage)
├─ 8 维时序特征向量 (销售/毛利/客流/同比)    │  (不参与标准化、MDM排序与门禁)
├─ 尺度不变性 MDM 粗排与 Top-K 初选          │
├─ SCM 自适应凸二次规划求解 (w_k >= 0)       │
├─ 训练集卡尺门禁仲裁 (Tier 1 / Tier 2 / 3)   │
│                                            │
▼                                            ▼
[最终入选对照集 C_i] ───────────────────────► 盲测诊断: Holdout RMSPE 测算
  ├─ Tier 1: 纯真实单店 (单店偏差<=10%)      │ (未见真实流水评估泛化能力，
  ├─ Tier 2: SCM 虚拟克隆 (合成偏差<=20%)    │  严禁反向调参或二次剔除)
  └─ Tier 3: 未获可比对照 (沉底未匹配专表)   │
      │                                      │
      ▼                                      ▼
进入 Step 4 四期等长 DDD 净增量闭环评估 ◄─────┴───────────────────────────────┘
```

1. **候选供体集 (Control Donor Set, $\mathcal{D}_i$)**：
   - 与试点店 $i$ 同营运区、同事前店型（DTP / O2O 重点店 / 常规成熟店）的合规成熟在营候选池；
   - 门禁要求：开业满 365 天（$\text{opert\_open\_date} \le S_i - 365\text{D}$），无历史政策调优与并发试验污染，事前基期日均流水 $> 100$ 元且客流 $> 5$ 单，事前 90 天数据完整上报；
   - 严禁跨店型降级回退，候选不足时如实进入未匹配专表。

2. **训练集 (Training Set, $T_{\text{train}}$: seg1 & seg2)**：
   - 实施日前 90D~31D（共 60 天），分为两段严格等长 30 天闭区间：
     - **seg1**：$[S_i - 90, S_i - 61]$（及去年星期对齐同期 $[S_i - 90 - 364, S_i - 61 - 364]$）；
     - **seg2**：$[S_i - 60, S_i - 31]$（及去年星期对齐同期 $[S_i - 60 - 364, S_i - 31 - 364]$）。
   - 提取 8 维分段时序特征向量：
     $$X = [\bar{S}_{\text{seg1}}, \bar{S}_{\text{seg2}}, \bar{\Pi}_{\text{seg1}}, \bar{\Pi}_{\text{seg2}}, \bar{O}_{\text{seg1}}, \bar{O}_{\text{seg2}}, g_{\text{YoY, seg1}}, g_{\text{YoY, seg2}}]$$
     （覆盖销售额、毛利额、订单量及同比增速）；
   - 用于特征标准化、MDM 距离初排、SCM 凸二次规划权重求解，以及训练集基线卡尺裁决。

3. **留出测试集 (Holdout Test Set, $T_{\text{holdout}}$)**：
   - 实施日前 30D~1D（共 30 天，闭区间 $[S_i - 30, S_i - 1]$），作为模型未见的事前盲测验证集；
   - **单向防火墙隔离（Zero Leakage）**：特征提取、标准化、MDM 排序、SCM 权重优化及门禁筛选中**100% 绝对不接触留出集**；
   - **事后盲测诊断**：在对位对照锁定后，在未见区间计算 Holdout RMSPE / 留出销售偏差：
     $$\text{Holdout RMSPE} = \frac{|\sum_{k} w_k S_{k, \text{holdout}} - S_{i, \text{holdout}}|}{\max(S_{i, \text{holdout}}, 1)}$$
   - 纯粹作为模型时序泛化能力的诊断证据，**严禁利用留出误差反向调整权重或二次剔除门店**。

4. **最终入选对照集 (Final Matched Control Group, $\mathcal{C}_i$)**：
   - **Tier 1 (纯真实单店)**：Top-1 MDM 候选店在训练集上满足严格门禁（$|\Delta S_{\text{train}}| \le 10\%$、$|\Delta O_{\text{train}}| \le 10\%$、$|\Delta \text{YoY}_{\text{train}}| \le 15\text{pp}$），赋予 $w=1.0$；
   - **Tier 2 (SCM 虚拟克隆)**：单店未达标，但 Top-K 供体凸优化克隆在训练集上满足合成门禁（$\text{Fit RMSPE} \le 1.0$、$|\Delta S_{\text{scm}}| \le 20\%$、$|\Delta \text{YoY}_{\text{scm}}| \le 20\text{pp}$），赋予凸组合权重向量 $w$；
   - **Tier 3 (未获可比对照排除区)**：单店与 SCM 均无法突破门禁，或同层候选池为空，沉底归入未匹配专表（记录原因如 `NO_SAME_STRATUM_DONOR`、`BASELINE_FIT_OUTSIDE_CALIPER`），**严禁跨层降级回退**。

### 2. 标准化空间马氏距离 (MDM) 与尺度不变性
在同店型候选池特征矩阵进行标准化（减均值除标准差 $z = \frac{x - \mu}{\sigma}$）后，利用正则化协方差逆矩阵计算马氏距离：
$$D_M(z_i, z_j) = \sqrt{(z_i - z_j)^T \mathbf{\Sigma}_{\text{reg}}^{-1} (z_i - z_j)}$$
其中 $\mathbf{\Sigma}_{\text{reg}} = (1 - \alpha)\mathbf{\Sigma} + \alpha \mathbf{I}$ 为加入对角岭的正则化协方差矩阵（默认 $\alpha = 0.01$）。
- **尺度不变性验证**：金额单位无论以“元”还是“万元”计入，标准化后的马氏距离与供体排序严格一致。

### 3. SCM 自适应凸组合优化与目标透明化
对于目标试点店 $i$ 及 Top-K 候选供体（$K=2\sim 3$）：
$$\min_w \| X_{\text{donors}} w - x_{\text{pilot}} \|^2 \quad \text{s.t.} \quad \sum_{k=1}^K w_k = 1, \quad w_k \ge 0$$
- **特征全面覆盖**：特征矩阵 $X$ 必须覆盖训练集 seg1 与 seg2 的销售额、毛利额、订单量及同比走势；
- **优化目标透明化**：明确披露毛利是否进入二次规划优化目标。若毛利纳入目标优化，如实列出权重；若毛利仅按销售权重线性合成，必须客观说明，不得宣称毛利已被最优合成。

### 4. 真实品类结构相似度 (Jensen-Shannon Distance，零虚假填充)
- 提取干预实施前各大类真实流水占比 $P, Q$，计算：
  $$JSD(P, Q) = \sqrt{\frac{1}{2} D_{KL}(P \parallel M) + \frac{1}{2} D_{KL}(Q \parallel M)}, \quad M = \frac{1}{2}(P + Q)$$
- 门禁要求：$JSD \le 0.20$；若某批次事前大类数据缺失，必须真实标记为缺失（NULL / 未测），**严禁使用任何经验常数（如 0.0888 等）进行硬编码填充**。

## 四、 规则驱动的基线硬卡尺裁剪与客观隔离

配对后的样本对必须经由训练集基线硬卡尺检验，触发任一门禁的门店沉底归入 Tier 3 排除区：
1. **卡尺 ① 事前销售体量偏差**：$|S_{\text{ctrl, train}} - S_{\text{pilot, train}}| / S_{\text{pilot, train}} > 20.0\%$（超出共同支撑集）；
2. **卡尺 ② 事前走势偏差**：$|\text{YoY}_{\text{ctrl, train}} - \text{YoY}_{\text{pilot, train}}| > 20.0\text{pp}$（偏离基期平行走势）；
3. **卡尺 ③ 供体历史基期不连贯**：对照供体去年同期曾停业跌幅 $> 70.0\%$ 或暴涨 $> 150\%$（基期数据断裂不可比）。

**严格杜绝事后选择偏差（No Conditioning on Post-Treatment Outcomes）**：
- 卡尺裁剪必须完全基于实施前训练集的基线特征与历史数据连续性；
- 严禁根据实施后的销售涨跌或 DID 结果反向剔除门店或调整参数；
- 若门店在实施后发生经业务证实的停业、迁址或不可抗力中断，应根据行政营运事实如实归档为行政受扰样本并独立披露，不可通过事后业绩跌幅门禁隐性筛选。

## 五、 三重差分 (DDD) 估算、客单价与两组独立评价

### 1. 三重差分 (DDD / YoY-DID) 核心公式
零售门店天然受月度季节性与长假周期及商圈惯性影响，必须执行三重差分闭环：
$$\text{DDD} = \underbrace{(\text{YoY}_{\text{pilot, post}} - \text{YoY}_{\text{pilot, pre}})}_{\Delta_{\text{试点提速增量}}} - \underbrace{(\text{YoY}_{\text{ctrl, post}} - \text{YoY}_{\text{ctrl, pre}})}_{\Delta_{\text{对照组提速增量}}}$$
其中 $\text{YoY}_{\text{post}} = (C - H) / H$，$\text{YoY}_{\text{pre}} = (L - LH) / LH$。明细交付必须同时报告基期同比、实施后同比与提速增量，杜绝口径混淆。

### 2. 客单价 (ATV) 计算规范
$$\text{ATV} = \frac{\text{Sales}}{\text{Orders}}$$
订单量为 0 时置为未定义/NULL，严禁倒置为 orders/sales。

### 3. 两组独立评价原则 (Dual Cohort Separation)
- 算法模型试点批次与历史业务调整批次为不同时期的非并发、非随机分组观察样本；
- **严禁将两组的 DID 估计值直接相减并解释为“模型相对人工经验的因果优势/劣势”**；
- 两组必须分别独立呈现 30D / 60D / 90D 的评估结果与差异归因。

### 4. 汇总与平均店级效果双轨报告与不确定性
- 同时报告组合汇总效果（Portfolio Aggregate DID）与单店平均效果（Average Store-Level DID）；
- 提供标准误（SE）与置信区间（CI），并显式考虑同一供体店被多家试点店复用时的相关性（Clustered/Reused Donor Standard Errors）。

### 5. 跨窗口固定对照池
- 在 30D、60D、90D 比较中，保持固定的对照基准池，并客观披露因窗口延长导致的部分门店数据覆盖不足与样本衰减。

## 六、 金字塔 4-Sheet Excel 与三层高管 HTML 交付规范

### 1. 金字塔 4-Sheet 格式化 Excel 交付架构
- **Sheet 1 评估结论总览**：
  - 锁定显式业务列名（`试点前销售同比(%)`、`试点店销售增量(pp)`、`DID销售净增量(pp)` 等）；
  - 三大模块：核心合格配对大盘（30D/60D/90D）、分营运区/分批次下钻、未获可比对照排除专表。
- **Sheet 2 试验组与对照组详细门店及指标（结果区与过程区彻底解耦）**：
  - **业务实证结果区**：展示试点与对照各自完整 DDD 链条（基期同比 $\to$ 后同比 $\to$ 增量 $\to$ DID 净增量），涵盖销售、毛利、客流、客单价；
  - **算法拟合过程与质量审计区**：展示最终对照销售拟合偏差、毛利拟合偏差、基期走势偏差、品类 JSD、留出测试集盲测 Holdout RMSPE，以及 1:1 单店锚点名称与偏差（解释启用 SCM 必要性）；未约束冗余指标坚决不展示。
- **Sheet 3 候选池分层与虚拟合成溯源**：同层供体池画像与 SCM 供体组成及权重（精确到 0.1%）。
- **Sheet 4 口径说明与计算字典**：DDD 闭环公式、四重卡尺门禁与术语定义。

### 2. 高管与业务汇报 HTML 交互大屏
- **CONSORT 矢量流转图**：展示试点筛选、分层互锁、卡尺裁剪与 Tier 1/2/3 分流漏斗；
- **大盘概览与区域决策**：以卡片和区域表格呈现核心 DDD 增量，彻底移除冗长逐店明细表（以 Callout 引导至 Excel 查阅）。
