# 对抗性审查

每次重跑至少完成以下检查：

1. 年度、日期起止、灰度日期均从本次 `project_et`/`cata_version_dt` 推导；生产 SQL/Python 不出现旧版具体日期或业务年度常量。
2. 大盘工作簿标题的起止日分别匹配本年和去年同期的严格 90 天窗口；历史对照快照只能按结束日显式匹配。
3. `cata_version_dt`、灰度快照、基线门店、主体明细和最终汇报的门店数逐层留证；异常门店数不得通过放宽条件掩盖。
4. 目录内字段、可比同比字段、组货字段逐个核对原始 SQL；不能把 `is_content_item_1`、`is_tb_sj`、`is_tg` 和 `is_kbtb_ct` 混用。
5. 公司发货窗口打印起止日并与加盟销售窗口区分；不能用旧版“从版本日到截止日”的区间替代动态发货窗口。
6. 模板格式复制不得覆盖新数值；图表缓存的类别、数值、差异行应与报告页单元格一致；桑基说明不得引用旧版数字。
7. 与旧版比对时分为：共同单元格数值、输入大盘共同字段、旧版缺失/新版新增内容。对日期窗口改变造成的差异必须单独说明。
