# 参数契约

## 日期推导

给定 `project_et` 和查询得到的 `cata_version_dt`：

| 参数 | 规则 |
| --- | --- |
| `project_et` | 显式传入；未传时为昨天 |
| `cata_version_dt` | `max(online_date)`，满足 `online_date <= project_et and jmlx='加盟'` |
| `project_st` | `cata_version_dt` |
| 灰度快照 | `cata_version_dt` 当天 |
| 加盟销售 | `project_et` 含截止日往前严格 90 天 |
| 加盟客流 | `project_et` 含截止日往前严格 56 天 |
| 公司发货起点 | 严格 90 天销售起点再减 30 天 |
| 公司发货 | 从上述起点含起始日统计严格 90 天 |
| 去年同期 | 每个端点分别减一年，闰日回退到 2 月 28 日 |

“严格 N 天”是含首尾的 N 个自然日：`start = end - (N - 1) days`。

## 字段语义

- 目录内：`is_content_vs_store = 1`。
- 加盟店组货可比：`is_tg = 1 and is_kbtb_ct = 1`。
- 加盟店大盘可比同比店：`is_tb_sj = 1`。
- 流转类型：最新分区中的 `fl`，并保留原值。
- 公司发货：使用与汇报范围一致的组货可比条件和本年/去年分区。

## 输出契约

- 首工作表为 `结论-组货口径-结果汇报版本`，从解密模板复制格式和图表关系。
- 桑基图下方先写动态说明，再写 `REPORT_SCOPE_NOTE`；禁止沿用历史固定金额。
- 应有中文表头、可比店/整体大盘列和 `省区明细`；图表包内应有三张图及桑基 PNG。
- 只输出汇报级聚合数据；禁止下载超过 1,000,000 行明细。
