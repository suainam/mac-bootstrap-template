# 陈列编码业务解构与传输规约 (Display Code Grammar & System Contract)

在门店空间陈列与货位分析中建立标准的编码解构与业务语义透传机制。

## 核心主导词 (Leading Words)

- **`【编码解构 / display-code-grammar】`**：采用标准的“中类代码 + 规模节数 + 顺位分节 + 自由标记”结构，解析货位物理含义。
- **`【原样透传 / transparent-passthrough】`**：数据清洗与指标层原样透传手工补充标识码，由下游陈列引擎结构化解析。
- **`【业务首要 / business-code-first】`**：报表与看板以业务识别码（陈列编码）作为主显示标识，技术句柄退居支撑位。

---

## 1. 陈列编码四段式解构模型

$$\underbrace{\text{CC}}_{\text{陈列中类 (2位)}} \quad \underbrace{\text{SS}}_{\text{总节数/长度代号 (2位)}} \quad \underbrace{\text{P}}_{\text{顺序分节 (1位，可选)}} \quad \underbrace{\text{-N}}_{\text{子面/端头 (可选)}}$$

| 语法段 | 类型 | 说明 | 解析示例 |
| :--- | :--- | :--- | :--- |
| **`CC`** | 2位数字 | 对应 `dim_scm_mid_category_df.scm_mid_category_no` | `02` (化痰止咳), `11` (OTC外用), `12` (营养素), `50` (心脑血管), `99` (OTC阴凉) |
| **`SS`** | 2位数字 | 货架连排规模与长度代号 | `10` (1节1米), `15` (1个1米+1个0.5米), `20` (2节1米), `30` (3节1米), `40` (2个1米+2个0.5米) |
| **`P`** | 1位字母 | 连排顺序顺位序号 | `A` (第1节), `B` (第2节), `C` (第3节), `D` (第4节) |
| **`F`** | 特殊单字符 | **空货架标记 (Free Shelf)** | 门店现场自由分配与动态陈列 |

---

## 2. 典型业务示例与解析结果

```
- 0210   -> 02中类 (化痰止咳) 绑定 1 个独立货架
- 0215A  -> 02中类 绑定 1个1米架 + 1个0.5米架之 A 节 (1米主架)
- 0215B  -> 02中类 绑定 1个1米架 + 1个0.5米架之 B 节 (0.5米辅架)
- 0220A  -> 02中类 绑定 2个1米货架之 A 节
- 0220B  -> 02中类 绑定 2个1米货架之 B 节
- 0240A  -> 02中类 绑定 2个1米架 + 2个0.5米架之 A 节
- F      -> 空货架，供门店自主机动陈列
```

---

## 3. 系统交付与报表契约

1. **表格列名规范**：统一命名为 **【陈列编码】**，不使用中间衍生词；
2. **图面呈现规范**：将陈列编码作为加粗主标居中展示，第二行呈现中类全称；
3. **数据一致性验证**：提取的编码前 2 位必须能通过中台维表映射为合法的陈列中类。
