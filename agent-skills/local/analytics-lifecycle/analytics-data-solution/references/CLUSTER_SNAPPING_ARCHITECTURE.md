# 空间组团吸附与拓扑对齐架构规范 (Cluster Snapping & Spatial Alignment)

在空间陈列与门店布局制图中，通过空间几何吸附消除图元交叉与错位，构建高保真矢量拓扑。

## 核心主导词 (Leading Words)

- **`【组团外框 / cluster-perimeter】`**：连排货架与展岛以物理组团（Cluster）为单位构建外轮廓线，保持整体建筑质感。
- **`【轴心吸附 / axis-snapping】`**：侧面端架与附属展台严格吸附于主货架中央轴线，杜绝基于单边锚点的视觉飘移。
- **`【双面中轴 / dual-side-divider】`**：双面中岛设置居中虚线分界线，清晰区分 A/B 双面独立品类。

---

## 1. 组团化几何构建原则

在二维平面绘制门店货架时，将物理连续的货架聚合为组团单元：

```
+-----------------------------------------------------------+ [组团外轮廓框线]
|  [端架A]  |         [双面中岛 100cm (A面)]         |  [端架B]  |
|           | - - - - - - - - - - - - - - - - - - - -|           | [中央中轴虚线]
|           |         [双面中岛 100cm (B面)]         |           |
+-----------------------------------------------------------+
```

### 1.1 轴心对齐公式
对于侧面端架（Endcap）与主中岛（Island）：
$$Y_{\text{center, endcap}} = Y_{\text{center, island}} = Y_{\text{base}} + \frac{H_{\text{island}}}{2}$$
$$Y_{\text{top, endcap}} = Y_{\text{center, island}} - \frac{H_{\text{endcap}}}{2}$$

### 1.2 空间通道净空保障
在连排调配柜台与垂直靠墙货架交汇处，预留 $\ge 10\text{cm}$ 安全视觉走廊，消除由于外框线宽度产生的边缘干涉。

---

## 2. 空间矢量构建审查标准

1. **零交叉断言**：所有静态货架的二维闭包多边形交集面积严格为 0；
2. **边缘无缝吸附**：同组同排相邻货架的边缘距离误差 $< 0.1\text{cm}$；
3. **建筑外廓完整**：布局图必须叠加店铺实体外墙与关键通道尺寸标注。
