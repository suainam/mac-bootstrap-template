# 回溯五问 (Cohort Backtrace Five Questions)

**触发**：任何指标用「本期名单」回溯「上期」销售（例如今年标签名单回溯去年同期）。上期数值偏低时，业务会质疑「是不是没匹配上」。交付前先答这五问，再写结论。

| # | 问题 | 检查方法 | 判定 |
| :--- | :--- | :--- | :--- |
| 1 | 匹配粒度是什么？ | 读 SQL 的 JOIN 条件，确认 `store_code + item_code` 店品对，而不是单独按商品或按门店 | 店品对级才算无遗漏匹配 |
| 2 | 商品编码还有效吗？ | 名单去重商品，统计上期全公司有销售的占比 | 占比高（本次 98.8%）说明缺的是铺货，不是编码失效 |
| 3 | 门店数一致吗？ | 对比两期「有销售的门店数」与「有目录快照的门店数」，并算缺快照门店在本期的销售占比 | 占比小（本次 9.6%）则门店数不是主因 |
| 4 | 差距来自覆盖还是强度？ | 销售额倍数 = 动销店品数倍数 × 单动销店品金额倍数 | 覆盖倍数占主导（本次 4.85× vs 1.18×）说明是铺货差异 |
| 5 | 新品与老品各贡献多少？ | 按「上期是否在该店目录」把店品对分两组，各自对比两期销售 | 老品持平、新品放量，说明是铺货从 0 到 1，不是经营改善 |

## 结论写法

- 差额主要来自覆盖时，写「去年这些品没铺进这些店」，不写「去年卖得差」。
- 上期标签快照里该标签为 0 行时，必须写明「该标签体系上期不存在」。
- 同比倍数不得当经营考核指标。老品同比才反映同店同品的经营变化。

## 范例

`topics/o2o_store/05_delivery/md/demand-adhoc-o2o_store-2026101914-05-delivery.md` 第 6 节：5.73× = 4.85× × 1.18×，老品 +4.1%，新品 5.77 → 62.79 万。
