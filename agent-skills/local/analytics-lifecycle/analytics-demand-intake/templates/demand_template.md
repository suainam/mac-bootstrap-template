## 2. 业务决策契约 (Business Decision Contract)

### 2.1 真实业务决策意图 (True Decision)
* **决策主体**：谁（营运经理 / 选品专员 / 战略高管）
* **决策时机**：在何时（月度考核 / 调仓补货 / 策略上线前）
* **触发动作**：依据此数据采取什么实际行动（淘汰商品 / 调整陈列 / 补发奖惩）

### 2.2 核心假设与反事实对比基准 (Counterfactual Baseline)
* **业务假设**：为什么认为该策略能带来预期变化？
* **对比基期 (Baseline)**：
  - [ ] 去年同期 H（等长闭区间，向前推 364 天星期对齐）
  - [ ] 上线前 L（往前推同等天数，排除大促异常期）
  - [ ] 合成控制对照组 SCM（基于事前特征 1:N 匹配克隆）
  - [ ] 外部未试点省区 / 平行对照营运区

### 2.3 分母防卫与边界排除 (Denominator & Non-Goals)
* **分母范围**：计算比例时的合法分母实体范围。
* **主动排除边界 (Non-Goals)**：
  - 排除开业不满 365 天的新店（避免爬坡期噪音）；
  - 排除基期日均流水 $\le 100$ 元或客流异常闭店门店；
  - 排除特定强监管限价区域（如新疆、冀晋蒙暂不纳入测算）。
