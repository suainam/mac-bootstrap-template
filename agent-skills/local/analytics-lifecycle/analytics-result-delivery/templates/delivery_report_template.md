# 交付报告通用规范模板 (Delivery Report Template)

> **业务用语净化契约 (Executive Jargon Purge ★)**：  
> 呈报高管与业务方的交付文档中，必须全局替换以下工程与空间测绘黑话：  
> - `延米` $\to$ **`陈列架长度 (米)`**  
> - `米效` $\to$ **`月均米效 (元/米·月)`** 或 **`每米陈列架产出`**  
> - `分母` $\to$ **`货架硬件基数`**  
> - `笛卡尔积膨胀` $\to$ **`重复累计 / 混陈双计`**  
> - `实体主键` $\to$ **`门店编码`**

1. **主结论**：`[一句话说明策略/算法在终端的真实表现]`；
2. **贡献结构**：`[以多少比例的品项，撬动了多少比例的销售额与毛利]`；
3. **差异根因**：`[单店未达预期的真正核心归因（如供应链断货、手工冗余、大盘走势）]`。
