# 技术方案与 SOP

适用于中文技术方案、SOP、报告、演示文稿。只删冗余和说教语气，技术含义、适用条件、禁止事项、操作目的全部保留。不得为追求简洁或专业感改变操作含义。

## 直接给方案

写操作、参数、前置条件、结果。删掉不提供实质信息的写作说明。

「用于阐明机制」这类表述若说明真实研究目的，保留。

## 写出技术前提

「在条件允许时」换成原稿有依据的具体前提，例如「标定前提：……」。换成另一个含糊说法（「条件允许时」「视情况」「必要时」「酌情」）等于没改。

「仅在……时」「若欲……需要……」承载必要条件时保留或等义改写，不得改成无条件动作。

条件在原稿里不明时，指出缺失信息，不自行补一个条件。

## 用操作语言

直接写处理规范，删「切记」「务必注意」这类说教语气。

必要的禁止事项和技术结论保留。「不可互相替代」若表达真实限制就保留。

「两者独立记录并平行分析」只在流程确实要求并行记录时使用；它不表达不可互换。

## 用准确动词

「进行……的测量」「对样品进行温度测量」都写「测量样品温度」。动作的对象和动作本身直接相连，不加「进行」。

「测量」「表征」本身就是准确动词。「标定」「解耦」「淬灭」「钳定」只在确实是那个操作时用；为显得专业而换词属于改变操作含义。

## 自谦改事实

| 原稿 | 改写 |
|---|---|
| 本文仅在两个数据集上做了初步尝试，只能提供有限参考 | 本文在两个数据集上评估该方法 |
| 该方案仍有很大提升空间 | 该方案在 X 条件下的 Y 指标为 Z |
| 我们只是简单地验证了一下 | 我们在 X 条件下验证了 Y |

「初步」「可能」「提示」确实符合研究情况时保留。不为了显得有力而加「显著」「全面领先」。

## 保留清单

改写前先圈出不能动的内容，改写后逐条核对：

- 参数值、单位、阈值
- 条件与顺序
- 禁止事项
- 失败后果
- 版本、日期、来源
- 不可互换、不可替代、互斥这类关系判断
