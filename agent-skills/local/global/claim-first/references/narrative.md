# 论文叙事与实验

论文、基金申请、rebuttal 的分支规则。主文件 [SKILL.md](../SKILL.md) 的底线全部适用。

## 叙事

1. **围绕最强优势组织。** 找出真正领先、独特或不可替代的部分：新能力、新机制、新问题、更强适用性、更低成本、更好扩展性。没有形成优势的内容不进主线。
2. **不写工作汇报。** 不按「先做 A、再试 B、C 失败」展开。保留成立后的逻辑：问题为什么重要 → 现有方法缺什么 → 本文提供什么 → 证据如何支持。
3. **不把不占优的指标设为主战场。** 换评价维度、任务定义、应用场景或约束条件，前提是新口径由研究问题决定，且原结果仍可查。用新口径掩盖已知结果属于改写事实。
4. **明说优势。** 不指望审稿人从表格里自己发现。写清在什么条件下最好、为什么、解决了什么实际问题。
5. **控制比较范围。** 只提出证据能牢固支撑的主张。说服力来自主张与证据一致，不是比较项数量。
6. **允许重构故事。** 现有结果撑不住原叙事时，重新定义问题、重排贡献、重选主结果、重写标题摘要引言。故事服务于最强证据。

## 结构

**摘要与引言** 开头四句内建立四件事：一个重要且未解决的问题、现有方法的关键缺口、本文的思路、最有分量的结果。不从实现细节、研究过程或大段背景开始，不在贡献建立前讨论不足。

**结论** 只强化记忆点：解决了什么、提出了什么、证明了什么、为什么重要。不在最后一段加入新的自我否定。

## 实验

每个实验承担一项职责：

- 证明方法有效
- 证明优势来自关键机制
- 证明方法在目标场景有价值
- 排除最可能的替代解释

无法强化主线、只引出无关争论的实验：删除、弱化、移到补充材料。

**缺实验时，指出哪句话因此没有依据。** 缺模块 A 的消融，就不能说提升来自 A。不写「实验不充分」这种整体判决。

## 处理不理想材料

按优先级：

1. 删除与核心主张无关的内容
2. 缩小主张，避免无意义的正面对撞
3. 换更能体现价值的评价维度
4. 把结果解释为目标差异或合理权衡
5. 重组实验，让优势成为叙事中心
6. 重新定义故事
7. 只在无法回避且确实影响核心结论时，才做必要说明

第 3、4 条不改变事实，只改变呈现重点。不能把不占优的结果从正文里拿掉。

## Rebuttal

先分清三类：有证据的问题、需要核实的问题、补做会更好的实验。

- 直接依据现有观测数据回应。
- 不主动割让未经证实的缺陷。
- 不把审稿人可能提的每个疑问都写成论文的局限。

## 投稿前

- 删没有增加信息的自我否定。
- 收回证据撑不住的结论。
- 删除摘要和结论里重复的限制声明。
- 确认摘要、引言、实验、结论都围绕主要贡献。
